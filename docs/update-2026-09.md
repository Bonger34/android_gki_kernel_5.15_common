## 四、编译修复（本次新增）

- **`lib/lz4/lz4hc.c`**：本次更新范围内，`linux/minmax.h` 开始提供 `MIN`/`MAX`；`-Werror`（`CONFIG_WERROR=y`）下 `lz4hc.c` 的本地定义（缺 `#undef`，与 `lz4.c`、`lib/zstd` 的写法不一致）触发 `-Wmacro-redefined`。
  **修复**：补上 `#undef MIN` / `#undef MAX`（与 lz4.c / zstd 相同模式）。
- 说明：该问题在原始 2025-07 树上不存在（当时 minmax.h 尚无 MIN/MAX），属于本次更新引入的适配点。

  - **兼容性结论：本次内核更新不需要更新该模块**（详见下方核查）
  - SHA-256：`a28d809bc85bb8b69fad213a91dd2c9a2f2eee52bd7bd665f851523aa5192337`

**刷入与使用（参考上游作者酷安帖 https://www.coolapk.com/feed/58959644 ）**：

- ⚠️ **刷入前请备份！！**
- 内核刷入：**Kernel Flasher**（作者推荐）/ KernelSU / Magisk / recovery
- 模块刷入：KernelSU 或 Magisk
- root 兼容性：只替换内核（boot 分区），不触碰 init_boot；Magisk / KernelSU（LKM）的 root 无需重新修补
- schedhorizon 切换模式：**scene** 或 **perapp-rs**；游戏切 **fast**；balance 按骁龙 8 Gen 2 调校（其他处理器可自行调参或不装模块）
- 上游备用下载（123云盘）：https://www.123pan.com/s/VdQQTd-91IH

**模块兼容性核查（2026-09-13）**：

| 模块依赖的内核接口 | 旧内核 | 新内核 | 合并影响 |
|---|---|---|---|
| `schedhorizon` 调速器（`kernel/sched/cpufreq_schedhorizon.c`） | 有 | 有 | **无（文件 byte 级完全一致）** |
| `schedhorizon/efficient_freq`、`up_delay` 属性 | 46 处 | 46 处 | 无 |
| `scaling_min_freq_limit` 节点 | 4 处 | 4 处 | 无 |

- 模块为纯用户空间调参脚本（无内核代码、无版本耦合逻辑）；频率数值为设备相关（SM8550 OPP 表），与内核版本无关
- 上游实践佐证：最近 4 个内核版本（v25.01.16 / v25.03.18 / v25.06.15）均沿用同一模块 `20241107`——模块仅在自身有改动时才更新

## 八、使用方式

### 方式 A：bundle（保留 git 历史）

```bash
# 1. 完整克隆原仓库
git clone https://github.com/hfdem/android_gki_kernel_5.15_common.git
cd android_gki_kernel_5.15_common

# 2. 从 bundle 拉取（全历史版）
git fetch /path/to/hfdem-5.15-2026-09-update.bundle \
  'refs/heads/android13-5.15-2026-09:refs/heads/android13-5.15-2026-09'
#   或净变更版（任意含 2025-07 分支的仓库均可）

  'refs/heads/android13-5.15-2026-09-net:refs/heads/android13-5.15-2026-09'

# 3. 检出
git checkout android13-5.15-2026-09
```
